# machin3d-overlay 3.1.0

Follow-up to 3.0.0 that moves the three remaining Bambu-specific
subcommands — `login`, `devices`, and `mqtt` — into the same `bbl-`
namespace as the Bambu CLI flags introduced in 3.0.0. The Snapmaker
`snap-pair` subcommand and the vendor-neutral `serve` are unchanged.

## Breaking changes

### Bambu subcommands moved into a `bbl-` namespace

| 3.0.0 subcommand | 3.1.0 subcommand |
| ---------------- | ---------------- |
| `login`          | `bbl-login`      |
| `devices`        | `bbl-devices`    |
| `mqtt`           | `bbl-mqtt`       |

Same arguments and behavior, just a prefix. Update any service units,
scripts, or shell aliases that invoke these subcommands. The `--device` flag
on `bbl-mqtt`, the `--bbl-cloud-device` / `--bbl-local-device` flags on
`bbl-mqtt` and `bbl-devices`, and the cached-token error messages emitted
when no token is present continue to work as before.

`serve` (vendor-neutral) and `snap-pair` (Snapmaker-specific) keep their
names — only the three Bambu-only subcommands are renamed.
